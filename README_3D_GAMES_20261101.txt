ZEMITA v70 - 3D 원버튼 게임 14종 추가 (2026-11-01)

[올리는 법]
이 폴더 전체를 기존 사이트에 그대로 덮어써서 올리세요.
- index.html : 비밀번호는 그대로 (기존과 같음). 안에 14개 게임 메뉴가 추가됨
- og/ 폴더   : 3D 게임 파일 14개 (같은 비밀번호로 잠겨 있음, 꼭 같이 올려야 함)
- sw.js      : 캐시 버전 zemita-v70 으로 올림 (새 버전 바로 반영)

[게임 방식]
- 동시 대결: 인원수만큼 화면을 나눠 각자 자기 센서로 동시에. 끝나면 점수 순위
- 차례대로: 한 화면에서 1P부터 순서대로 하고 점수 비교
- 맞대결(테니스·탁구): 한 코트에서 1P(왼쪽) vs 2P(오른쪽). 3~4명이면 이긴 사람이 남기
- 화면 위치는 기존 "화면 나누기" 설정을 그대로 따름

[참고]
- 잠금 도구로 나중에 다시 잠그면, 3D 게임을 처음 열 때 비밀번호를 한 번 더 물어볼 수 있어요
  ("이 폰에서 기억하기"를 켜 두면 안 물어봐요)
- 3D 게임은 three.js를 인터넷(jsdelivr)에서 불러와서 인터넷 연결이 필요해요
