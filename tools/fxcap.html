이펙트 수집기 북마크

코드가 짧아서(약 230글자) URL 칸에 다 들어가요. 진짜 수집기는 누를 때마다 여기서 새로 불러와요.

처음 한 번만
  1. 위 버튼으로 코드를 복사해요.
  2. 크롬 ⋮ → ☆(별)로 아무 페이지나 북마크 추가 → 수정
  3. 이름은 fx수집, 주소 칸은 전부 지우고 복사한 코드를 붙여넣기 → 저장
먼저 여기서 시험해 보기

이 페이지 주소창에 fx수집을 쳐서 ☆ 북마크를 눌러 보세요. 왼쪽 아래에 노란 테두리 창이 뜨면 성공이에요.

쓸 때마다
  1. 크롬으로 이펙트를 가져올 사이트를 열어요.
  2. 게임 화면이 열린 상태에서 주소창을 누르고 fx수집을 쳐요. 아래 목록에 ☆ 별 모양으로 뜨는 북마크를 눌러요 → 왼쪽 아래에 수집 창이 떠요.
    북마크 목록(⋮ → 북마크)에서 누르면 크롬이 실행을 안 해요. 꼭 주소창에서!
  3. 배틀을 해서 기술을 여러 개 써 보세요. 이펙트가 화면에 나와야 파일이 잡혀요.
  4. ZIP 저장 → 받은 zip을 채팅에 올려 주세요.

잡힌 게 적으면 "이펙트 아닌 것도 전부"를 켜고 다시 저장해요.

주소창에 코드를 직접 붙여넣으면 크롬이 앞의 javascript:를 지워서 안 돼요. 꼭 북마크로 만들어서 눌러요.
