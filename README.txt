이 압축 안의 poke 폴더를 GitHub 저장소(attack)의 poke 폴더에 그대로 덮어써서 올리세요.
- poke/index.html : 게임 본체 (기술 연출 레이어 + 이펙트 에디터 연결)

- poke/fxed.html  : 이펙트 에디터 (게임 관리자 화면의 🎛 버튼으로 열려요)

[쓰는 법]
1) 게임 관리자 → 🎬 기술 이펙트 관리자 → 맨 위 🎛 이펙트 에디터 열기
2) 만들고 「저장」 탭에서 이름 적고 「게임에 저장」 → 서버에 자동으로 올라가요 (✓ 표시 확인) → 닫기
3) 관리자 목록 「🎛 내 이펙트」에서 기술에 고르기
4) 아이들 기기: 저장하면 서버에 올라가서 몇 분 안에(앱을 다시 열 때도) 자동 적용돼요. 파일 업로드는 필요 없어요.
   (poke/fxed.json 은 서버가 안 될 때의 기본 목록이에요)
